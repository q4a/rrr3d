# macOS application artwork

`AppIcon.png` is a square crop of the original Motor Rock
`Data/GUI/startLogo.dds` resource supplied with the game data. `RRR3d.icns`
contains the standard 16, 32, 128, 256, 512, and 1024 pixel macOS icon
representations generated from that crop.

The icon is packaged only by `RRR3D_BUILD_MACOS_BUNDLE`; it is not required by
the portable command-line milestone targets.

`Licenses` contains the project and third-party notices installed beside the
icon in `Contents/Resources/Licenses`.
