## Подтверждённый пункт без локального закрытия

### F-003

Факт подтверждён: macOS target по-прежнему собирает переносимые `Original*`,
bgfx и Jolt реализации вместо прямой компиляции значительной части старых
Windows/D3D9/PhysX object graphs. В рамках этой проверки все конкретные
расхождения F-004…F-047 устранены сравнением с исходным кодом, но это не
устраняет будущий риск новых расхождений. Для полного закрытия F-003 нужен
отдельный архитектурный этап с постепенным переносом и подключением оригинальных
классов либо с исчерпывающей ветвевой верификацией каждой замены.
